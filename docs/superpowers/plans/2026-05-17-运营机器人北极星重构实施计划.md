# 运营机器人北极星重构 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 AI Boot 重构成低打扰、高有效的群运营机器人：统一 Qwen3.5 Flash，图片异步评分，放宽 C/S/G 高价值行为得分入口，持续晋升但不周期末放水，并提供运营侧低噪声摘要。

**Architecture:** 保持现有 v2 可见积分为生产事实源，继续让 v3 shadow 作为审计评分链路。新增图片理解缓存和异步图片 worker，聊天上下文只使用图片描述；新增运营意图路由和低噪声通知策略；晋升规则改为多路径持续判断，重点要求 C/S/G 贡献证据。

**Tech Stack:** TypeScript, Node.js, Fastify, SQLite, Vitest, Feishu OpenAPI, OpenAI-compatible DashScope 百炼接口。

upsertAiBootImageUnderstanding(input: AiBootImageUnderstandingRecord): void {
  this.db.prepare(
    `INSERT INTO ai_boot_image_understandings
      (content_hash, file_key, message_id, model_name, caption, score_hint,
       latency_ms, status, error_reason, created_at, updated_at)
     VALUES
      (@contentHash, @fileKey, @messageId, @modelName, @caption, @scoreHint,
       @latencyMs, @status, @errorReason, @createdAt, @updatedAt)
     ON CONFLICT(content_hash) DO UPDATE SET
       file_key = @fileKey,
       message_id = @messageId,
       model_name = @modelName,
       caption = @caption,
       score_hint = @scoreHint,
       latency_ms = @latencyMs,
       status = @status,
       error_reason = @errorReason,
       updated_at = @updatedAt`
  ).run(input);
}

findAiBootImageUnderstandingByContentHash(contentHash: string): AiBootImageUnderstandingRecord | null {
  const row = this.db.prepare(
    `SELECT * FROM ai_boot_image_understandings WHERE content_hash = ?`
  ).get(contentHash) as Record<string, unknown> | undefined;
  return row ? {
    contentHash: String(row.content_hash),
    fileKey: String(row.file_key),
    messageId: String(row.message_id),
    modelName: String(row.model_name),
    caption: String(row.caption),
    scoreHint: String(row.score_hint),
    latencyMs: Number(row.latency_ms),
    status: String(row.status) as AiBootImageUnderstandingRecord["status"],
    errorReason: String(row.error_reason),
    createdAt: String(row.created_at),
    updatedAt: String(row.updated_at),
  } : null;
}
```

export async function understandImageForAiBoot(input: {
  repo: {
    findAiBootImageUnderstandingByContentHash(hash: string): AiBootImageUnderstandingRecord | null;
    upsertAiBootImageUnderstanding(record: AiBootImageUnderstandingRecord): void;
  };
  feishuClient: Pick<FeishuApiClient, "getMessageFile">;
  llmClient: AiBootLlmClient;
  messageId: string;
  fileKey: string;
  contentHash: string;
  now: () => string;
}): Promise<AiBootImageUnderstandingRecord> {
  const cached = input.repo.findAiBootImageUnderstandingByContentHash(input.contentHash);
  if (cached?.status === "succeeded") return cached;
  const started = Date.now();
  const now = input.now();
  input.repo.upsertAiBootImageUnderstanding({
    fileKey: input.fileKey,
    messageId: input.messageId,
    contentHash: input.contentHash,
    modelName: input.llmClient.visionModel || input.llmClient.model,
    caption: "",
    scoreHint: "",
    latencyMs: 0,
    status: "running",
    errorReason: "",
    createdAt: cached?.createdAt ?? now,
    updatedAt: now,
  });
  // 下载图片、调用模型、解析 JSON，并写回 succeeded 或 failed。
}
```

具体解析规则：模型只输出 JSON，字段为 `caption`、`scoreHint`、`isAiArtifact`、`suggestedScore`。失败时写 `failed`，`caption=""`，`scoreHint=""`，`errorReason` 为错误前 160 字。

- [ ] **Step 2: 修改晋升规则**

在 `continuous-promotion.ts` 中实现：

```ts
function hasCsgEvidence(dimensions: ContinuousDimensionTotals): boolean {
  return dimensions.C > 0 || dimensions.S > 0 || dimensions.G > 0;
}

function meetsLv2Primary(cumulativeAq: number, dimensions: ContinuousDimensionTotals): boolean {
  return cumulativeAq >= 24 && hasCsgEvidence(dimensions);
}

function meetsLv2StrongWork(cumulativeAq: number, dimensions: ContinuousDimensionTotals): boolean {
  return cumulativeAq >= 32 && countDimensionsAtLeast(dimensions, 8) >= 1;
}

function meetsLv2Excellence(cumulativeAq: number, dimensions: ContinuousDimensionTotals): boolean {
  return cumulativeAq >= 20 &&
    countDimensionsAtLeast(dimensions, 5) >= 2 &&
    (dimensions.C >= 5 || dimensions.S >= 5 || dimensions.G >= 5);
}
```

`meetsContinuousPromotion` 的 Lv1 分支使用这三条路径。

```ts
export type OperationsIntent =
  | { kind: "admin_command" }
  | { kind: "score_candidate" }
  | { kind: "score_opt_out" }
  | { kind: "learner_qa" }
  | { kind: "praise_candidate" }
  | { kind: "ordinary_chat" };

export function classifyOperationsIntent(input: {
  text: string;
  mentionedBot: boolean;
  messageType: string;
}): OperationsIntent {
  const text = input.text.replace(/\s+/g, "");
  if (/不用加分|不要加分|别加分|纯瞎聊|撤回加分/.test(text)) return { kind: "score_opt_out" };
  if (input.mentionedBot && /怎么|如何|为什么|哪里|作业|提交|规则/.test(text)) return { kind: "learner_qa" };
  if (input.messageType === "image" || /我用AI|AI做|海报|复盘|经验|试了|客户/.test(input.text)) return { kind: "score_candidate" };
  return input.mentionedBot ? { kind: "ordinary_chat" } : { kind: "ordinary_chat" };
}
```
